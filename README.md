# Retail Analytics Assignment

## Project Overview
This project analyzes retail sales data using Python.
## Files Included
- Retail_Analytics.ipynb
- Superstore.csv
- retail_analytics_problemstatement.txt
## Libraries Used
- pandas
- numpy
- matplotlib
Install libraries:
pip install pandas numpy matplotlib

## Analysis Performed
- Profit by Category
- Profit by Sub-Category
- Regional Sales Analysis
- Discount Impact
- Loss Making Products
- Customer Segment Analysis
- Shipping Analysis
- Monthly Sales Trend
